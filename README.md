# Бот курса USD из Eurasian Bank → Telegram (через GitHub Actions)

Бот будет работать на серверах GitHub бесплатно, твой компьютер при этом
включать не нужно. Раз в ~30 минут GitHub запускает скрипт: он открывает
страницу банка в фоновом браузере, читает курс USD во вкладке «В Smartbank»
и шлёт тебе сообщение в Telegram, **только если курс изменился**.

---

## Что тебе понадобится

- Аккаунт в Telegram (уже есть)
- Аккаунт на GitHub (создадим в шаге 1)
- Эти четыре файла: `eubank_usd_bot.py`, `requirements.txt`, `check-rate.yml`, `README.md`

---

## Шаг 1. Зарегистрироваться на GitHub

1. Открой [github.com/signup](https://github.com/signup).
2. Введи email, пароль, придумай username (он будет виден в адресе репозитория).
3. Подтверди email — GitHub пришлёт письмо со ссылкой.
4. На вопрос про план выбери **Free** — этого хватит с большим запасом.

## Шаг 2. Создать Telegram-бота

1. В Telegram найди **@BotFather** и открой с ним чат.
2. Отправь команду `/newbot`.
3. BotFather спросит имя бота (любое, например «Курс USB Eurasian») и
   username (должен заканчиваться на `bot`, например `eubank_usd_yelena_bot`).
4. В ответ придёт сообщение с **токеном** вида
   `1234567890:AAH-xxxxxxxxxxxxxxxxxxxxxxxxxxx`. Скопируй и сохрани его.

## Шаг 3. Узнать свой chat_id

1. Найди в Telegram своего нового бота (по username из шага 2) и нажми **Start**
   или просто отправь ему любое сообщение — например, «привет». Это важно:
   пока ты не написала боту первая, он не сможет тебе отвечать.
2. Открой в браузере ссылку, подставив свой токен вместо `<ТОКЕН>`:
   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```
3. В ответе найди фрагмент `"chat":{"id": 123456789, ...}` — это и есть твой
   **chat_id**. Сохрани его (это просто число, обычно 9 цифр).

## Шаг 4. Создать репозиторий на GitHub

1. На [github.com](https://github.com) нажми **+** в правом верхнем углу →
   **New repository**.
2. **Repository name:** любое, например `eubank-usd-bot`.
3. **Public** или **Private** — выбери **Public** (для публичных репозиториев
   GitHub Actions бесплатны без лимитов; код там типовой, секретов в нём нет).
4. Поставь галочку **Add a README file**.
5. Нажми **Create repository**.

## Шаг 5. Загрузить файлы

В созданном репозитории:

1. Нажми кнопку **Add file** → **Upload files**.
2. Перетащи туда из проводника **три файла**:
   - `eubank_usd_bot.py`
   - `requirements.txt`
   - `README.md` (можешь не загружать — у тебя уже есть автоматический README,
     но лучше залить мой, в нём вся инструкция)
3. Внизу нажми **Commit changes**.

Теперь нужно отдельно загрузить файл расписания, **обязательно** в подпапку
`.github/workflows/`:

1. Снова нажми **Add file** → **Create new file**.
2. В поле имени файла **впечатай вручную**:
   `.github/workflows/check-rate.yml`
   (когда напечатаешь `/`, GitHub сам поймёт, что это вложенные папки).
3. В большое поле ниже **скопируй всё содержимое** файла `check-rate.yml`,
   который я тебе подготовила.
4. Внизу нажми **Commit changes**.

## Шаг 6. Положить токен и chat_id в Secrets

Это безопасное хранилище — ни в коде, ни в логах твои данные видны не будут.

1. В репозитории открой вкладку **Settings** (вверху справа).
2. В левом меню: **Secrets and variables** → **Actions**.
3. Нажми **New repository secret**.
4. **Name:** `TELEGRAM_TOKEN`, **Secret:** вставь токен от BotFather.
   Нажми **Add secret**.
5. Снова **New repository secret**.
6. **Name:** `TELEGRAM_CHAT_ID`, **Secret:** вставь свой chat_id (число).
   Нажми **Add secret**.

## Шаг 7. Разрешить Actions писать в репозиторий

Скрипту нужно сохранять файл `last_rate.json` обратно в репозиторий, иначе
он на каждом запуске будет «забывать» прошлый курс.

1. **Settings** → в левом меню **Actions** → **General**.
2. Прокрути до раздела **Workflow permissions**.
3. Выбери **Read and write permissions**.
4. Нажми **Save**.

## Шаг 8. Запустить вручную в первый раз

1. Открой вкладку **Actions** в репозитории.
2. Слева увидишь workflow **Check USD rate** — нажми на него.
3. Справа кнопка **Run workflow** → **Run workflow** (зелёная).
4. Через несколько секунд появится новый запуск (жёлтый кружок → потом
   зелёная галочка). Длится примерно 1–2 минуты.
5. Если всё правильно — в Telegram придёт сообщение с текущим курсом.

После этого бот будет запускаться автоматически каждые ~30 минут и слать
тебе сообщение, **только когда курс реально поменялся**.

## Что делать, если что-то не работает

**В Telegram ничего не пришло после ручного запуска.**
Открой запуск во вкладке Actions, нажми на job `check`, разверни шаги
и посмотри, на каком из них красный крестик. В тексте ошибки обычно
сразу видно проблему.

**Ошибка `chat not found`.**
Значит, ты не написала боту первая (см. шаг 3, пункт 1). Отправь ему
любое сообщение и запусти workflow ещё раз.

**Ошибка `Unauthorized` или `401`.**
Токен скопирован с пробелом или не до конца. Удали Secret `TELEGRAM_TOKEN`
и создай заново, скопировав токен от BotFather полностью.

**Ошибка `Не удалось распарсить курс`.**
Eurasian Bank поменял вёрстку страницы. Напиши мне — поправим селекторы
в `eubank_usd_bot.py`.

**Хочу проверять не каждые 30 минут, а раз в час.**
В файле `.github/workflows/check-rate.yml` поменяй строку
`- cron: "*/30 * * * *"` на `- cron: "0 * * * *"` (каждый час в 00 минут).

**Хочу временно отключить бота.**
**Settings** → **Actions** → **General** → **Disable actions**.
Включить обратно — там же.
